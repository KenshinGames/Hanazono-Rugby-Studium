# 資料と寸法の出どころ

東大阪市花園ラグビー場 第1グラウンド(2018年9月の改修後)を作るために使う数字と、その出どころ。
調べた日: 2026-11-17

確かさの印:
- **公式** … 市・運営者・設計や施工にかかわった会社の資料に書いてある
- **実測** … 空中写真や地図データから自分で測った(誤差の目安つき)
- **推定** … 写真の見た目や一般的な寸法から決めた。⑨の見比べで直す対象

## 1. 座標の決まり

| 項目 | 値 | 確かさ |
|---|---|---|
| 単位 | Blender の 1 = 1 m | 決まり |
| 原点 | フィールドの中心(ハーフウェイラインの中点)、芝の面が Z=0 | 決まり |
| +X | タッチラインの向き。北スタンド(大型映像装置)の側 | 決まり |
| +Y | 西。メインスタンドの側 | 決まり |
| +Z | 上 | 決まり |
| +X の方位 | 真北から西へ 14.3°(方位角 345.7°) | 実測(OSM の芝の外形の長辺。±1°) |
| 緯度・経度 | 北緯 34.668917 / 東経 135.626250 | Wikipedia(日本語版) |

スタンドの呼び名は公式の座席案内に合わせる: 西=メイン(屋根あり)、東=バック、北、南。

## 3. 実測した数字

測り方: 国土地理院のシームレス空中写真(ズーム18、1画素 0.491 m)を 14.3° 回してグラウンドをまっすぐにし、
フィールド中心から 10 m ごとの目盛りを重ねて読んだ。あわせて OpenStreetMap の外形を同じ座標に直した
(`tools/osm_measure.py`)。誤差の目安は ±1 m。

| 項目 | 値(m) | メモ |
|---|---|---|
| ゴールポストの間隔 | 100 | 空中写真で 2 組のポストが ±50 m に写っている。規定どおり |
| 芝の範囲 | X −67.4 〜 +68.6、Y ±40.8(約 136 × 82) | 天然芝の濃い緑の範囲 |
| 芝の外の緑の帯 | 芝の端から壁まで 2〜5 m | 人工芝らしい明るい緑 |
| 西スタンドの前の壁 | Y = +43 | OSM は +41〜42 |
| 東スタンドの前の壁 | Y = −42.5 | OSM は −43.2 |
| 北スタンドの前の壁 | X = +72 | OSM は +72.6 |
| 南スタンドの前の壁 | X = −73 | OSM は −75.3。前は緑の帯が弧になっている |
| 東スタンド | X −66 〜 +71、Y −42.5 〜 −68(奥行 約 26、長さ 約 137) | 1 層 |
| 北スタンド | 前 X=+72 で Y ±36、後ろ X=+92 で Y +43 〜 −45(奥行 約 20) | 後ろへ広がる台形 |
| 西スタンドの建物 | X −65 〜 +75、Y +43 〜 +84(北寄りの X>+45 は +75.5 まで) | 奥行 約 41 |
| 西スタンドの屋根 | 主部 X −67 〜 +40、Y +54 〜 +83 / 北部 X +40 〜 +72、Y +54 〜 +77 | 前の数列は屋根の外 |
| 南スタンドの直線部 | X −73 〜 −117、Y ±34(奥行 約 44) | 座席 |
| 南の両脇のコーナー | 直線部の両側から東西スタンドの南端まで弧でつながる立見の段 | 外周は X=−114.7 の直線から (X≈−75, Y≈±70) へ回り込む |

## 5. 推定で作る所(わからなかった所)

| 項目 | 仮の値 | 決め方 |
|---|---|---|
| インゴールの奥行 | 10 m | 規定は 6〜22 m。芝はゴールラインの先 18 m まであるが、写真ではデッドボールラインの外に余白がある。②で 2019 年の写真に合わせて決める |
| ゴールポストの高さ | 17 m | ワールドカップ時の写真の見た目から |
| 各スタンドの段数と蹴上げ | config/dimensions.json の stands | 公式の席数に合うよう、奥行(実測)から段数を逆算した。作った席は 21,555(西 6,663 / 東 7,020 / 北 2,470 / 南 5,402)。公式の一般席の合計は 21,538 |
| 東スタンドの高さ | 最上段 約 15 m | 奥行 26 m と写真の傾きから |
| 北スタンドの高さ | 最上段 約 14 m。映像装置の枠は Z 15〜25 m | 南のゴール裏からの写真(2023-04)で、表示面の縦 8.16 m を物差しにして測った |
| 南スタンドの高さ | 最上段 約 22 m | 写真から(2階席と3階席の2段) |
| 西スタンドの屋根 | 上面は先端 27 m、後ろ 24 m(前が高い)。柱は客席の中(前の壁から 19.5 m)と上のコンコース | バックスタンドからの写真(2024-06)で映像装置を物差しにして先端を約 25 m と測り、メインスタンドの写真と見比べて 1 m 上げた |
| 照明塔 | 高さ 約 37 m。位置は北西 (88, 45)、北東 (91.5, −60)、南西 (−79, 73)、南東 (−80, −67) | 高さは 2023-04 の写真で映像装置を物差しにして測った(最初の見積もり 48 m は高すぎた)。位置は空中写真に写った柱の根元から |
| 381 台の内訳 | 塔 1 基 72 台(4 段 × 18 列)× 4 + 屋根の先端 93 台(12 かたまり) | 合計が公式の 381 になるよう割りふった。枠は幅 約 18 m × 高さ 約 5.6 m(写真から) |
| 座席の段数・列の幅 | 席数と面積から逆算(段の奥行 0.8 m、席の幅 0.48 m を基準) | 写真の段数と合わせる |
| 映像装置の左右位置 | ほぼ中央 | 写真から |
| 芝の種類・刈り目の幅 | 縞の幅 約 5 m | 写真から |
| 座席の色 | 赤が基本。東スタンドは下半分に青で「HANAZONO」の文字。南の両脇は席なしのコンクリートの段 | 写真から |

スクラムスクリーン(南の正面)は図面がなく、高さ 23.6 m、斜めの帯の周期 11.8 m、両脇の弧は半径 43 m・高さ 20.5 m と写真から決めた。
菱形のタイルの並びは実物どおりではなく、灰色の濃淡とガラスを乱数(種は固定)で割りふっている。
東の遠くの山(生駒山)は、バックスタンドの上にのぞく高さが写真と合うように置いた板で、実際の距離や形ではない。

## 7. 架空にするもの

- スタンドやグラウンドの周りの企業の広告看板、映像装置の下の看板 → 架空の社名とロゴ
- 映像装置に映す内容 → 架空の対戦表示
- 大会のロゴや装飾(ワールドカップ 2019 など) → 入れない
- 「HANAZONO RUGBY STADIUM」の文字と、座席で描いた「HANAZONO」は施設名なのでそのまま再現する
