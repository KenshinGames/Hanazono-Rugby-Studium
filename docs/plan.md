# 計画

東大阪市花園ラグビー場 第1グラウンド(2018年の改修後)を Blender で再現する。
寸法と出どころは [reference.md](reference.md)。進み具合は [../PROGRESS.md](../PROGRESS.md)。

## 環境

- Blender 5.3.0(`/opt/homebrew/bin/blender`、Python 3.13)。画面は開かず `blender -b` で動かす
- Mac M4・メモリ 16 GB・GPU は Metal が使える。空き容量は約 15 GB
- 描画は Cycles(GPU)。ffmpeg で動画と比較画像を作る

## ファイルの構成

```
config/dimensions.json   寸法をまとめた唯一の設定ファイル(ラインの位置、スタンドの外形、高さ、色)
scripts/build.py         入口。これを流すと build/hanazono.blend ができる
scripts/hz/              部品ごとのモジュール
  config.py                dimensions.json を読む
  util.py                  メッシュ・マテリアルの共通の道具
  pitch.py                 ②芝、ライン、ゴール、フラッグ、周りの舗装、ベンチ
  stands.py                ③スタンドの段とコンクリートの躯体
  roof.py                  ④メインスタンドの屋根と骨組み
  seats.py / details.py    ⑤座席、通路、手すり、出入口
  screen.py / lights.py    ⑥映像装置、照明塔、屋根の先端の投光器
  exterior.py              ⑦スクラムスクリーン、外壁、周りの地面
  materials.py / sky.py    ⑧質感、昼と夜の光
  cameras.py               決まった角度と、参考写真に合わせた角度
scripts/render.py        確認用・仕上げ用の静止画
scripts/orbit.py         一周する動画
scripts/compare.py       参考写真と並べた比較画像
run.sh                   build / stills / video / compare をまとめて流す
docs/                    reference.md、plan.md、compare/(比較)、remaining.md(残った違い)
out/                     描き出した画像と動画(git に入れない)
build/                   .blend(git に入れない)
refs/                    参考写真(git に入れない)
```

## 作り方の方針

- 手作業なし。形はすべて `config/dimensions.json` の数字から Python で作る。乱数は種を固定し、何度流しても同じ結果にする
- 部品ごとにコレクションを分け、`build.py --only pitch` のように一部だけ作り直して確認を速くする
- 座席は約 2 万 4 千席。1 脚の形を 1 つ作り、ジオメトリノードで点の上に並べる(メモリを抑える)。色は点ごとの属性で持ち、東スタンドの「HANAZONO」の文字は点の色分けで描く
- 芝の縞は形ではなくマテリアルで出す(位置から縞を計算)。近くで見る角度だけ細かい凹凸を足す
- ラインやゴールの位置は設定ファイルから読む。あとで試合を足すスクリプトも同じファイルを読めば位置が合う
- 文字(看板、施設名)は Blender のテキストで作る。日本語は Mac に入っているヒラギノを使う
- 広告は架空の社名にする

## 段階

各段階の終わりに確認用の画像を out/ に出し、自分で開いて参考写真と見比べてから次へ進む。段階ごとにコミットして push する。

| 段階 | 作るもの | 確認用の画像 |
|---|---|---|
| ①資料調べと計画 | reference.md、plan.md(済み) | — |
| ②グラウンド | 設定ファイル、芝と縞、ライン、ゴールポストとパッド、フラッグ、芝の外の緑の帯と舗装、ベンチ | 真上、斜め、ゴール裏 |
| ③スタンドの大きな形 | 四方の段の断面と外形、南の両脇の弧、躯体の箱 | 真上(空中写真と重ねる)、四隅から |
| ④屋根と骨組み | メインスタンドの屋根、立体トラス、柱 | メインスタンド正面、下から見上げ |
| ⑤細部 | 座席と色分け、縦通路、出入口(ボミトリー)、手すり、VIP・放送席の箱、北スタンド下のガラスの部屋 | 各スタンドの寄り |
| ⑥映像装置と照明 | 映像装置と時計・脚、照明塔 4 基、屋根先端の投光器、旗のポール | 北スタンド、塔の寄り |
| ⑦外側と周り | スクラムスクリーン、外壁、前の広場の舗装、隣のグラウンドや道の簡単な形、植え込み | 外観 2 方向、空から |
| ⑧質感と光 | コンクリート・鉄骨・座席・芝の質感、昼の晴れ(実際の方位で太陽を置く)、夜(投光器を実際の位置で光らせる) | 5 つの角度 × 昼夜 |
| ⑨見比べ | 参考写真と同じ角度で描いて並べ、違いの一覧を作って大きい順に直す。目立つ違いがなくなるまで繰り返す | docs/compare/ |

## 仕上げで出すもの

- 静止画 5 角度 × 昼夜 = 10 枚(中継風の高い位置 / ゴール裏 / 客席から / 空からの見下ろし / 外観)。3840×2160
- 一周の動画 約 30 秒(1920×1080、30 コマ/秒、昼)。1 コマの時間を測ってから、Cycles で足りるか決める
- docs/compare/ … 参考写真と並べた比較。docs/remaining.md … 残った違いとできなかったこと

## 自分で決めたこと(違っていたら言ってください)

1. **向き**: +X を北スタンド側、+Y をメインスタンド(西)側にする
2. **比較画像の扱い**: 並べた比較は docs/compare/ に置いて git に入れる(小さめの JPEG)。参考写真は再利用が許されている Wikimedia Commons のものだけを使い、作者とライセンスを書く。公式サイトや Panasonic の写真は見るだけに使い、比較画像には入れない。out/ の描き出しと .blend は git に入れない
3. **再現する時点**: 2018年の改修後の通常の姿。ワールドカップのときの仮設の席・仮設の映像装置・大会の装飾は入れない
4. **施設名の文字**(外壁の HANAZONO RUGBY STADIUM、座席の HANAZONO)は再現する。企業名はすべて架空にする
5. **観客は入れない**(空席の状態)

## わかっている難所

- 高さの公式な数字がない。写真にカメラを合わせて逆算するので、±2 m ほどの誤差は残りうる
- スクラムスクリーンは斜めの柱が重なる曲面で、正確な図面がない。写真から柱の本数と傾きを読んで作る
- メインスタンドの屋根の骨組み(立体トラス)は部材が多い。写真で数えられる範囲で合わせる
- 空き容量が 15 GB と少ない。動画のコマは書き出し後に消す
