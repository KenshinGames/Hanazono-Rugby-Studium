# インスタのリール 台本(第 3 版)

- 縦 1080×1920、**40 秒**、24 コマ/秒、音なし
- 決まったこと(2026-11-18):
  - 字幕・文字は入れない。必要なら書き出した動画にあとで足す
  - 音楽はインスタのアプリで探して付ける
  - 長さは 40 秒
- 第 2 版を見た本人の感想と、第 3 版での直し(2026-11-18):

| 感想 | 第 3 版 |
|---|---|
| 毎回止まった所から動き出すので、ぶつ切りに見える | どのカットも最初から最後まで一定の速さで動く。最後のカットだけ、終わりに向けてゆっくり止まる |
| 照明が点く場面が、町が夜になったあとに来ていて時間の流れに乗れていない | 時刻をカットごとに進める(昼下がり → 夕方 → 夕焼け → 日暮れ → 夜)。照明は日暮れの空がまだ青いうちに点く |
| 全体に速すぎてシネマティックでない | 速さを 3〜10 分の 1 に。スライダーは歩く速さ、ドローンは時速 10〜40 km くらい |
| Claude と Blender のロゴは最初がよい | 冒頭 0.3〜3.0 秒に小さく出す(画面は暗くしない) |
| 1 カット目は夜に | 夜の七色の外壁から始める |
| 夕焼けと、昼の日差しを変えたい | 昼の場面は低い日差し(太陽の高さ 16〜27 度)。夕焼けは本物の夕焼けの空(太陽の高さ 0.6 度)を描く。昼と夜を重ねるのはやめた |
| 昼間は町を見せすぎない | 真上や空高くからの昼の絵をやめ、スタジアムの中や低い所から撮る |
| 遠くの山(生駒山)が一番花園らしい | 生駒山を作り直し(谷と尾根、山頂のテレビ塔と夜の赤い灯)、望遠で山を大きく見せるカットを足した |

## 流れ

| # | 時間 | 時刻 | 撮り方 | 映すもの |
|---|------|------|--------|----------|
| 1 | 0.0〜3.5 | 夜 | **スライダー**(横へ 1.2 m/秒) | 七色の外壁と赤い施設名。冒頭に Claude × Blender のアイコン |
| 2 | 3.5〜8.5 | 昼下がり(27 度) | **ドローン**(南西の角の上を横へ、少し上がる) | 屋根の影の落ちたグラウンド、HANAZONO の客席、照明塔、奥に生駒山 |
| 3 | 8.5〜12.5 | 昼下がり(25 度) | **スライダー**(地面から 1.4 m、0.7 m/秒) | 日の当たる芝とゴールポストの長い影。奥にメインスタンドと太陽 |
| 4 | 12.5〜16.5 | 夕方前(16 度) | **ドリー**(屋根の下を進む、見上げ) | 白い鉄骨のトラスと柱、赤い客席 |
| 5 | 16.5〜21.5 | 夕方(5 度) | **望遠 60 mm のスライダー** | バックスタンドの向こうに夕日の当たる生駒山とテレビ塔。手前の客席だけが流れ、山は動かない |
| 6 | 21.5〜25.5 | 夕焼け(0.6 度) | **ドローン 上昇** | バックスタンドの上から西へ。上がると、メインスタンドの屋根の上に夕日が出る |
| 7 | 25.5〜30.0 | 日暮れ(−3.5 度) | **ティルトアップ** | 青い空に暗い照明塔。見上げていくと照明が点く(一瞬消えてまた点く)。**山場** |
| 8 | 30.0〜35.0 | 夜 | **ドローン 周回**(2.4 度/秒) | 光るスタジアムと町の灯り。奥に生駒山の影と、山頂の赤い灯 |
| 9 | 35.0〜40.0 | 夜 | **ドローン 上昇しながら後退**(最後にゆっくり止まる) | スタジアムが町の灯りの中の一点になる。最後の 0.7 秒で黒へ |

## 作り

- コマを描く: `blender -b build/hanazono.blend -P scripts/reel.py --`(続きから描ける。`--test` で各カット 3 枚だけ、`--preview` で全部のコマを小さく)
- 動画にまとめる: `python3 scripts/reel_assemble.py` → `out/hanazono_reel.mp4`(`--preview` で試写版)
- 時刻ごとの光は `scripts/hz/tod.py`。空・雲の色・霞・窓や外観の明かり・投光器を時刻に合わせる
- 色はまとめるときにカットごとに整える(`reel_assemble.py` の `GRADE`)。描き直さずに直せる
- 動きのぶれ(モーションブラー)あり。ゴールポストのカットだけ背景を少しぼかす
- 電車は最後のカットで線路を走る(遠いのでほとんど見えない)
- アイコンは Mac のアプリから取り出す(各社の商標なので git には入れない)
