# インスタのリール 台本(第 2 版・決定)

- 縦 1080×1920、**40 秒**、24 コマ/秒、音なし
- 決まったこと(2026-11-18):
  - 字幕・文字は入れない。必要なら書き出した動画にあとで足す
  - 音楽はインスタのアプリで探して付ける
  - 長さは 40 秒
  - 最後に Claude と Blender のアイコンを並べ、この 2 つで作ったとわかるようにする
- 構成: 昼で始めて夜で盛り上げる。真ん中で日が暮れ、照明が点く瞬間を山場にする
- 冒頭は昼の外壁から入る(夜の七色はカット 10〜12 で見せる)

## 作り

- コマを描く: `blender -b build/hanazono.blend -P scripts/reel.py --`(続きから描ける。`--test` で各カット 3 枚だけ小さく)
- 動画にまとめる: `python3 scripts/reel_assemble.py` → `out/hanazono_reel.mp4`
- 動きのぶれ(モーションブラー)あり。ゴール裏のカットだけ背景を少しぼかす
- 電車は線路と別の物にして、夜は窓が灯る(最後のカットで線路を走る。遠いのでほとんど見えない)
- アイコンは Mac のアプリから取り出す(各社の商標なので git には入れない)
